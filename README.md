Веб-приложение для диагностики природных талантов на основе методологии CliftonStrengths (Gallup).

Адаптировано для специалистов в области HR, кадрового делопроизводства и управления персоналом.

🚀 Как запустить
Сохраните код в файл с расширением .html
(например, test_talents.html)

Откройте файл в любом браузере (Chrome, Edge, Firefox, Safari)

Работает без интернета (кроме загрузки страницы)

📋 Возможности
Функция	Описание
Ввод ФИО	Идентификация участника
12 вопросов	Выбор между двумя утверждениями + степень уверенности
Расчёт топ-5 талантов	«Стратег», «Обучаемость», «Развитие других», «Аналитик», «Ответственность», «Эмпатия», «Адаптивность», «Конкуренция»
Расширенная интерпретация	Описание, типичная ситуация, совет, тень — для каждого таланта
HR-рекомендации	3 направления карьеры с подробным обоснованием
Сохранение результатов	Печать или сохранение в PDF (через диалог браузера)
История участников	Все результаты сохраняются в браузере (localStorage)

🧠 Логика подсчёта
Каждый вопрос даёт баллы в 1–2 темы

Уровень «скорее» — базовые баллы

Уровень «однозначно» — усиленные баллы

Топ-5 = 5 тем с максимальной суммой баллов

👥 Для кого
HR-специалисты — для самодиагностики и понимания своих сильных сторон

Руководители — для осознания управленческих талантов

Кандидаты в HR — для выбора карьерного трека

Тренеры и методологи — для понимания своей роли (публичный тренер vs методолог)

⚠️ Важно
Это не официальный тест CliftonStrengths (Gallup Access).
Сервис — диагностическая модель на основе открытой методологии.
Официальный тест содержит 177 вопросов и требует лицензии Gallup.
